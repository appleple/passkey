パスキー管理

このプラグインは、Ver. 3.3.0 で本体機能として公式提供を予定している機能のプレビュー版です。本体機能との互換性はないため、3.3.0 へのアップデート後はパスキーの再登録が必要になります。本プラグインの配布およびメンテナンスは、3.3.0 のリリース後に終了を予定しています。

サイトに登録されている全ユーザーのパスキー一覧です。退職や端末紛失などで無効化が必要な場合はここから削除できます。

パスキーの登録がありません。

まだどのユーザーもパスキーを登録していません。「パスキーを作成」から自分のパスキーを登録できます。

フック拡張が無効のため、パスキーが利用できません。

ログイン画面への「パスキーでログイン」ボタンの追加などにフック機能を使用しています。サーバー上の config.server.php を開き、次のように変更してください。 

define('HOOK_ENABLE', 1);
