パスキーの登録がありません。

生体認証や PIN、セキュリティキーでパスワードレスログインができます。

同梱ライブラリが見つからないため、パスキーが利用できません。

プラグイン内の vendor ディレクトリがサーバー上に存在しません。アップロード時に欠落した可能性があります。配布物の extension/plugins/Passkey/vendor/ を、ディレクトリごと再アップロードしてください。

フック拡張が無効のため、パスキーが利用できません。

ログイン画面への「パスキーでログイン」ボタンの追加などにフック機能を使用しています。サーバー上の config.server.php を開き、次のように変更してください。 

define('HOOK_ENABLE', 1);

パスキーを追加

  1. 登録したいパスキーの名前を入力して「パスキーを追加」を押してください。
  2. ブラウザがお使いの認証器（Touch ID / Face ID / Windows Hello / Android の生体認証や画面ロック / ハードウェアセキュリティキーなど）に登録を求めます。

他のユーザーのパスキーはここでは管理できません。

パスキーは各ユーザー本人がログインした状態で、自分のユーザー管理ページから登録・削除します。
